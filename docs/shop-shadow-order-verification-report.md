## 3. 自动化验证结果

`scripts/shop-feature-local-acceptance.sh` 已通过以下场景：

1. 后台登录、CSRF 和排除 UID 校验。
2. 网页支付不再返回商城购买确认页。
3. 网页支付保留原支付插件响应。
4. MAPI 不再返回商城 jump，保留原 API 响应契约。
5. 原商户 UID、金额、商品名、`param` 和通道不变。
6. 随机充值商品快照与原支付单一对一。
7. 重复提交不重复创建支付单或商城单。
8. 排除商户不创建商城记录。
9. 原商户只入账一次，原商户通知正常。
10. 商城表临时不可写时，原支付仍继续。
11. CLI 补齐未支付漏单。
12. CLI 补齐已支付漏单并直接标记已发货。
13. CLI 不为排除商户补建商城单。
14. 商城公共查询显示已支付、已发货。
15. `checkout` 回滚模式仍可打开购买确认页。
16. Playwright 移动查询页、桌面商城和管理后台无横向溢出或前端报错。

自动化结果标记：

```text
PLAYWRIGHT_SHADOW_ACCEPTANCE_OK
SHOP_SHADOW_ACCEPTANCE_OK
```
