## 继续操作与回退

服务器的 `proof-control.py` 可在受控窗口创建并撤除临时证明检查入口，`database-control.php` 的启用动作会核验私有验收记录后才允许更新配置。本轮已完成该核验与启用。后续观察真实新请求的汇总结果，不补写历史 IP，不自动把旧单纳入配额或投诉封禁。公网收银页的缓存旁路覆盖范围仍按实际路径验收与维护，不能由单个自检路径推断全站覆盖。

需要回退应用时先关闭采集并刷新配置缓存，再切回上一版本并平滑 reload PHP FPM。ESA 已切 HTTPS 后，必须保留源站 HTTPS 监听、证书、续期和既有鉴权规则；应用回退不能同时撤掉已在使用的 HTTPS 回源通路。
