## 启用与回退

本次是部署，不是自动启用。旧单、有效订单路径的 CDN 不缓存、真机及商城结账仍需按实际商户核对。Weilaile 可以采用本地阻断与持续占位，但已发出的上游链接无法由平台撤销；未知占位不会因跨日或本地超时释放，真实付款通知继续验签和入账。

在商户全部关闭且没有接管记录的当前条件下，可保留增量表、配置和网络链路，原子切回前一目录并平滑 reload PHP-FPM。若之后已启用商户或执行接管，须先核对状态，并在回退代码中保留退役/本地阻断检查；不能直接切回缺少该检查的版本，也不能删除记录或恢复整库覆盖新交易。

方案、工具用法及持续占位边界见 [通道适配与旧订单接管](MERCHANT_DEFENSE_CHANNEL_TAKEOVER.md)。
