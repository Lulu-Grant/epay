# PHP 运行版本政策

当前维护分支仅支持 PHP **8.4.x**。新代码、依赖解析、CI、安装检查、运行环境验收和发布回滚都以 8.4.x 为准；不再要求保留旧版 PHP 语法或运行兼容。MySQL 下限仍为 5.7，或使用经验证兼容的 MariaDB。

`includes/composer.json` 和锁文件使用 PHP 8.4 平台；GitHub Actions 仅在 8.4 运行静态检查与数据库 fixture。应用统一入口、安装页和 `tools/php84/check-env.php` 均拒绝非 8.4 版本。发布回滚目标为上一个已验证的 8.4 构建，不切换到旧 PHP 运行时。

过去的升级验证报告和功能验收报告只记录当时的证据，不能覆盖本政策。判断当前支持范围时，以本文件、Composer 约束和 CI 配置为准。更新运行版本政策应与依赖锁、CI、安装检查及回滚手册一起审查。
